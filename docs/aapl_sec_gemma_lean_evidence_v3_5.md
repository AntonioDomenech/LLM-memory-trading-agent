1. Preserve the inherited position-preserving SEC-or-IMS envelope selection,
   authenticated filing-`TEXT` masking, exact family-marker grammar, nesting,
   original-byte decoding, and selected-header boundaries without change.
2. Define one plain legacy form pattern before family selection and use that
   same pattern for both a structurally SEC-only header and a structurally
   IMS-only header:

   `^[ \t]*CONFORMED SUBMISSION TYPE:[ \t]+([^\r\n]+)$`

   complete admitted separator grammar. Every contiguous ASCII space or tab

   the first byte that is neither space nor tab.

   `<CONFORMED-SUBMISSION-TYPE>([^\r\n<]+)` and

5. Across the two tagged patterns and the one family-neutral plain pattern,
   require exactly one total raw match. Require the captured raw value to equal

   family-specific fallback, alternate pattern, exception table, or retry.
7. Parse, hash, offset, select, normalize downstream text, and reconcile the
   original response bytes exactly as inherited. No alias body, projected SEC
   body, trimming, relabelling, or transformed diagnostic can become source
   evidence.
