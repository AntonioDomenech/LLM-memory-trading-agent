# AAPL SEC/Gemma lean science v3.17 preregistration rejection

## Decision

V3.17 is permanently rejected before an implementation commit, qualification,
one-shot preflight reservation, V3.17 private-source replay, Yahoo request,
Ollama request, Gemma generation, market-value read, prediction, action,
return, performance calculation, confirmation or live-style data open, paid
API, broker action, or real-money action.

The immutable V3.17 preregistration replaces a clause-insensitive market-
direction guard with one exact punctuation-preserving grammatical regex. Its
optional linking-verb group contains `is`, `was`, and `were`, but omits the
plural present-tense copula `are`. Because the document says the replacement
Boolean becomes exactly that regex result, a synthetic genuine-outcome control
such as `shares are higher` would not be rejected by the replacement rule.
The older V3.16 bag-of-words rule rejected that control.

Adding `are` after the preregistration was pushed would change an exact frozen
rule after review evidence existed. Implementing the known omission, silently
retaining the older bag-of-words rule, or weakening the synthetic control would
contradict the immutable preregistration. No V3.17 implementation is therefore
permitted.
